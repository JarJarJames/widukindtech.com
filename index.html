Services

What I can build for you

I work in native Swift for Apple platforms. You get one engineer who handles the whole job: design, architecture, code, testing and the App Store release.

New iOS apps

From an idea or a Figma file to a SwiftUI app on the App Store. I'll scope it with you, build it, put it on TestFlight and submit it.

Features & fixes for your app

I join your codebase, learn your conventions and start shipping. That includes new features, bug fixes, crash reduction, SwiftUI migrations and adopting new iOS releases.

Maps & location

Interactive Mapbox maps, CoreLocation, geofenced check-ins and offline content for places with no signal. I've built all of these for state parks.

Accessibility audits

VoiceOver, Dynamic Type and color contrast. I audit your app and write up the issues, then fix them myself or hand them to your team. I led the ADA work on the State Parks app.

macOS apps & tools

Native SwiftUI Mac apps, including ones that drive other processes, manage files, use the Keychain and talk to outside services. BEER is an example.

Offline, sync & reliability

Offline caching, sync that doesn't lose data, unit tests around the risky parts, and GitHub Actions CI. This is the work that keeps the support inbox quiet.
